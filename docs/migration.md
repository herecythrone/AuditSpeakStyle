# 从旧材料与0.1.0到0.2.0

## 主要纠偏

0.1.0先构造了不依赖上游的版本，只读取候选项目元数据与许可；这未满足“基于指定资本市场法律文风项目作审计适配”的核心目标。0.2.0不再把前版默认为主蓝本：先读取已确认上游相关正文，以其披露表达和复核机制重建写作主线，再吸收前版可用的审计补充。

不以文件数、静态检查通过数或版本号证明本版优于上游；也没有把本版重新整理等同于更多经验积累。本版交付的是可追溯改编及测试材料，独立运行效果仍须实际测量。

## 附录旧audit-writing-cn的评估

| 旧内容 | 决策 | 本版处理及理由 |
|---|---|---|
| 识别场景与读者 | 保留 | scenes区分底稿、正式说明、监管与沟通，不重复追问已有信息 |
| 最小充分修改、直接交付正文 | 保留并强化 | 与上游过度挑错反馈结合，用S12/R02/R03检查真正有用的改动 |
| 删除无信息套话 | 保留 | 改成具体主体动作，不机械封禁词表 |
| 原程序、事实、审计、法律“四层级” | 改写 | B05按性质区分，不是自动升级链条 |
| 小金额、拟不细究与对报表影响有限的转换 | 舍弃自动转换 | B04/E12明确金额、性质、判断需分别支持；不从800元作重要性结论 |
| 法律无风险换成对整体变更无重大不利影响 | 舍弃 | B06/E14指出两个结论都需各自依据，不以换对象规避缺口 |
| 未发现异常改成未发现明显异常 | 改写 | E09禁止无依据新加“明显”等门槛 |
| 外部法律意见转述 | 保留并具体化 | 来源、事项、时点和限制同时保留，不全面拒绝法律事项 |
| 内外转换 | 改写 | 不只换口吻；未完成、限制和待补证据在正文可见 |
| 旧例“用户已确认”标签 | 不迁移 | 新例为虚构教学材料，不标用户确认，也不保留真实客户数据 |
| 本机Word协作、应用配置 | 不纳入 | 与文风内核分离，不绑定个人路径或其他私有Skill |

## 0.1.0文件如何处理

重写SKILL与四份核心参考，新增review-method及安装随行PROVENANCE/许可；保留经复核的20组虚构案例并新增10组。旧26个行为案例经本版规则复核后保留，新增18个。复用并扩展前版检查器，原32个工具测试继续运行；新增来源和导出器测试另计，不把它们冒称语言模型测试。

README、HANDOFF、来源研究、许可证待决、验证报告等全部更新。旧身份未确认、不读取上游正文的描述仅在本迁移记录中作为历史事实；本版当前状态为来源明确且已实质改编。公开交付不包含原任务附件、旧版快照或私人聊天。

本包只交付文件；落盘时以清单涉及的同路径文件为替换范围。仓库额外文件和旧已安装audit-writing-cn不属于自动删除或覆盖对象。
