这项自检由同一编写助手完成，不是独立审计专家审阅、第二模型盲评或宿主运行。参考答案不是运行日志；54项工具通过不等于44例语言测试通过。本次没有独立模型输出可以用于计算行为通过率，因此不提供虚构通过率或相对上游的质量增幅。

部分行为测试与技能内教学例重叠；导出器不泄露独立答案字段，但被测技能本身可能包含相同或类似例句。这些用例用于规则回归与验收，不是独立留出集，也不能证明未见任务泛化能力。
