# 后续小规模模型测试

2026-09-22，在 Codex 中分别指定 GPT-5.6 Luna / GPT-5.6 Terra，推理强度 low，各新建两个对话，对比 AuditSpeakStyle 与旧 audit-writing-cn。每个技能/模型组合运行一次，在一个对话中批量执行相同六题。已回读工具记录，确认指定技能及适用参考文件实际读取成功。

六题覆盖正式说明、已有好文本少改、差异与证据、确定事实、底稿/微信/内部消息转换、法律结论边界。材料为虚构；这不是包内44例参考答案的执行记录。

## 观察

- 正式说明与最小修改：两个模型下两版输出大体接近。
- 差异与证据：均保留已查明和待验证的区别；个别语句仍不顺畅。
- 确定事实：四份回答都用了“主要系/主要由于”，而给定事实已完整解释变化，存在不必要限定。
- 动作状态：Luna旧版、Terra两版将“希望客户提供”写成“已要求/已催请”，新增了未给定的已完成动作；Luna新版本次未出现该错误。
- 年份：Luna两版在未给年份的题目中补入2025年；Terra两版本次未出现。
- 法律边界：均删除无依据的法律保证；Luna两版提出了超出题设形式要求的“专项评估”，Terra两版未再提出该要求。

这些结果不支持新版稳定胜出，也不代表可以不复核地直接使用。每种配置仅运行一次，未逐题隔离、未重复抽样、未设置无Skill基线，不计算稳定通过率或模型间因果差异。未验证自动触发；显式文件读取成功不等于所有宿主行为通过。

首次公开版仅补充许可和发布说明，未针对这些样本调整文风规则。上述问题仍是已知限制。
