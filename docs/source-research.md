# 来源研究：上游为主、官方样本校准

研究与核验日期：2026-09-22。本版首先使用已确认上游的表达与复核材料，详见 [上游研究](upstream-review.md) 和 [改编映射](adaptation-map.md)。以下是独立的官方公开样本校准，不是上游语料来源证明，也不证明某一例文字适用于所有项目。

## P01｜会计师专项说明：工作与意见分别写明

**来源标题**：《关于珠海高凌信息科技股份有限公司首次公开发行股票申请文件的第二轮审核问询函有关财务会计问题的专项说明》。容诚会计师事务所（特殊普通合伙），文号容诚专字[2021]518Z0528号。

[上交所披露PDF](https://static.sse.com.cn/stock/disclosure/announcement/c/202109/000874_20210930_4FVD.pdf)，URL披露目录日期为2021-09-30。

**实际范围**：读取相关解析正文，并查看PDF第1、12、13页截图。第12、13页印刷页码为8-2-2-11、8-2-2-12。未声称逐页审阅其余全部内容。

**原文观察**：相关合同事实与业务过程的说明，和后续“申报会计师核查意见”下的核查程序、核查意见分开；程序列明检查资料、访谈或核对对象，意见逐项回应对应事项。

**本版推导**：S07/S08及场景写法采用按问题交代事实、已执行程序及结果、受支持答复的组织方法。它改善可追溯性，但不表示每段必须三标题。不把样本中的合同事实、收入确认结论或程序清单复制成其他项目的工作记录。

## P02｜招股意向书摘要：数字、期间与变动对应

**来源标题**：《江苏利柏特股份有限公司首次公开发行股票招股意向书摘要》。注意这是“招股意向书摘要”，不是完整招股说明书，也不是会计师出具的专项意见。

[巨潮资讯披露PDF](https://static.cninfo.com.cn/finalpage/2021-07-06/1210419681.PDF)，URL披露目录日期为2021-07-06；解析结果为89页。

**实际范围**：读取封面/声明及“管理层讨论与分析”相关解析正文，重点为PDF第65—66页（印刷页码1-2-1-65、1-2-1-66）的财务状况与盈利能力段落。尝试第1、65、66页截图均返回错误或缓存缺失；未完成这些页的视觉核对，不以该样本作版式、表格视觉或数字转录验证。

**原文观察**：管理层讨论按期间列示金额，再说明增减方向、幅度与构成；它属于发行人披露语境。相应表达可以不依赖“显著改善”等笼统评价就把变动讲清。

**本版推导**：S03、S06和E03/E20借鉴期间—金额—变动的组织方式；全部教学数字另行虚构。发行人的原因解释不会因为被引用而变成会计师验证结果。本版没有对其历史财务数字或成因作真实性认证。

## N01｜审计边界：明显微小与不重大不能互换

[中国注册会计师协会官方PDF](https://www.cicpa.org.cn/xxfb/tzgg/202304/W020230410260829885045.pdf)：《〈中国注册会计师审计准则第1251号——评价审计过程中识别出的错报〉应用指南》，封面载明2023年4月4日修订。

**实际范围**：读取相关文本并查看PDF第1—2页截图。以正文和封面识别文件，不使用网页检索标题替代正文的准则编号。

**来源支持**：该指南区分明显微小与不重大，并涉及规模、性质、发生环境及汇总影响等判断因素。

**本版用途**：用于检查B04和对旧版小金额自动结论的纠正；不在Skill中内置阈值，不从金额单因素决定是否执行程序，不把本次选读说成已穷尽核验所有现行准则。
